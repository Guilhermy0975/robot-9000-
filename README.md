# Atomic BOT — site

Site estático do Atomic BOT (bot de WhatsApp).

- `index.html` — página principal (comandos, demo, roleta, plano, dúvidas)
- `roleta.html` — redireciona para a roleta do site
- `assets/` — artes

Configurações (número do WhatsApp, preços, prêmios da roleta) ficam no começo do `<script>` do `index.html`.

A versão anterior deste repositório (app Next.js) está na tag `backup-app-antigo`.
